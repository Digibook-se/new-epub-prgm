# New EPUB Program

Ett Python-projekt för att skapa och hantera EPUB-filer med GUI, inklusive integration mot Firebase.

## Funktioner

- Skapa och modifiera EPUB-böcker med PySide6 GUI
- Hantera PDF- och DOCX-filer som källmaterial
- Integrerad Firebase-administration för molnfunktionalitet
- Färgstark terminalutmatning med Colorama
